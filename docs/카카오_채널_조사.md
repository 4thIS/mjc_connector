# 카카오톡 접근 채널 조사 (2026-10-09)

> 방식: 카카오 공식 비즈니스 가이드(kakaobusiness.gitbook.io)·카카오 보도자료 원문을 Tavily로 추출·검색. Tavily 요청은 한 번에 하나씩 보냈고 마지막에 429(요청 과다)가 한 번 났다. 공식 사이트 `i.kakao.com`은 추출 시 "인증에 실패했습니다"만 나와 읽지 못했다.

## 경로 A. 카카오톡 채널 챗봇 (카카오 i 오픈빌더 + 스킬 서버)

[출처] 공식 비즈니스 가이드
- **가입**: 카카오 계정 + 카카오비즈니스 통합 가입 후 챗봇 관리자센터 회원가입. 별도 사업자 서류 언급 없음. 봇 만들기 버튼으로 바로 생성(개인 가능 여부는 가이드가 "누구나"라고 명시하지는 않음, 가입 절차에 사업자 요건이 안 나옴).
- **채널**: 운영 채널(실서비스)과 개발 채널(테스트) 둘이 필요. 채널 하나는 봇 하나에만 연결. 봇 마스터는 채널 매니저 이상 권한 필요. 채널의 채팅방 메뉴·자동응답 기능은 챗봇과 동시 사용 불가.
- **배포**: 설계·저장한 내용은 배포해야 운영 채널에 반영. 배포는 중지 불가, 최대 30분. 배포 실패 점검 항목에 "운영·개발 채널이 같은 비즈앱에 연결되어 있는지"가 있음 → **비즈앱 연결이 필요한지는 가이드에서 단정하기 어렵다.** 인증 블록·카카오싱크 플러그인은 비즈니스 인증이 필수이고, 일반 챗봇 응답만 쓰는 경우는 명시 없음 — 미검증.
- **스킬 서버**: 봇 시스템이 HTTP POST + JSON으로 호출. **공인 IP 또는 공중망 도메인만 사용 가능. 응답 제한 5초(고정).**
- **콜백(AI 챗봇용)**: 블록에서 콜백 옵션을 켜면 5초를 넘겨도 응답 가능. 콜백 URL은 **5분간 유효, 1회만 사용**. 즉 LLM을 질문 때마다 호출하는 구조도 기술적으로는 가능하다. 다만 그 LLM 비용은 우리가 내야 한다(Claude/ChatGPT 경로는 사용자 본인의 AI 구독이 비용을 낸다). 그래서 카카오 경로는 "수집 시 한 번 구조화 + 질문 때는 코드 판정"(LLM 비용 최소) 설계가 여전히 유리하다. 5초 제한만이 이유가 아니라 비용이 이유이다. 콜백은 봇 테스트 화면에서 완전히 동작하지 않아 배포 후 운영 채널에서 시험해야 한다.
- **요금**: 챗봇 채팅 서비스는 요금 없음. 봇이 먼저 말 거는 Event API는 메시지 건당 15원(VAT 별도)이며 월렛 필요 — 쓰지 않으면 비용 없음.
- **화면**: 텍스트·카드·버튼 위주의 말풍선. 표·좌석 현황판 같은 자유 UI는 한계.
- **개인정보**: 사용자의 카카오 정보를 받으려면 앱키 설정, 비즈 인증이 필요. 받지 않으면 불필요.

## 경로 B. PlayMCP (카카오의 MCP 플랫폼)

[출처] 카카오 보도자료(2025-11-24) + 블로그·영상 요약(공식 아님)
- 원격 MCP 서버만 등록 가능. 기능 검증·보안 점검 후 공개. 2026-05 기준 외부 MCP 약 200개(보도).
- 이용자는 카카오 계정으로 로그인해 **도구함**에 도구를 담고, **ChatGPT 개발자 모드 또는 Claude 커스텀 커넥터**에 도구함 주소를 한 번 등록해 쓴다. 즉 사용자 쪽에서는 결국 Claude/ChatGPT 설정이 필요하다. 모바일 접근성을 높이는 경로가 아니라 **등록·인증을 대신해 주는 허브**다.
- PlayMCP 사이트 안에 웹 채팅 테스트창이 있어 별도 AI 계정 없이 도구를 시험할 수 있다(블로그·영상 설명). 일반 이용자용 채팅 서비스인지는 확인되지 않음.
- 개발자는 비공개로도 등록해 본인만 테스트 가능(영상 설명).
- 2025년 영상에서 "ChatGPT in 카카오톡에서 플레이 툴즈를 쓰게 될 것"이라는 계획 언급이 있었으나, 현재 가능한지는 이번 검색(2회)에서 찾지 못함 — 미검증.

## 정리

- 모바일 접근성의 가장 큰 강점은 **카카오톡 채널 챗봇(경로 A)**: 학생이 이미 매일 쓰는 앱에서 설치·계정 추가 없이 채널을 친구 추가하고 말을 건다. (카카오톡이 국내 메신저 이용률 최상위라는 기사는 있으나 대학생 이용률은 확인 못 함.)
- 경로 A의 약점: 시연·UI 표현이 제한, 오픈빌더 가입·채널 연결·배포 절차와 숨은 요건(비즈앱 필요 여부)이 미확인, 응답 5초/콜백, 학생이 채널을 친구 추가해야 함(홍보 필요).
- 경로 B는 Claude/ChatGPT 입구를 보완하는 등록 허브이지 카카오톡 직접 입구가 아니다.
