# 개인정보 처리 방침 — MJC 커넥터 원격 서버

이 문서는 원격 MCP 서버(`https://mjc-mcp.hyeon02.dev/mcp`)가 다루는 정보를 적는다. 서버 코드는 이 리포의 `mjc_connector/server.py`다.

## 제공하는 도구

공지 목록·본문 조회, 도서관 열람실 좌석 현황, 학과 목록. 모두 학교 홈페이지에서 로그인 없이 누구나 볼 수 있는 공개 정보다. 로그인이 필요한 도구(강좌 검색·강의계획서)는 이 서버에 없다.

## 받는 정보

- 서버는 로그인이나 계정 정보를 요구하지 않는다. 이름·학번·연락처를 받지 않는다.
- 공지 해당 여부를 판정할 때 학과·학년·재학 상태를 받는다. 이 값은 그 요청의 판정에만 쓰고 저장하지 않으며, 서버 기록과 오류 문구에 남기지 않는다.

## 기록과 보관

- 서버는 사용자 데이터를 데이터베이스나 파일에 저장하지 않는다.
- 학교 사이트 조회가 실패할 때 쓰는 대체 캐시에는 학교 공개 페이지에서 받은 내용(공지 목록·좌석 현황 등)만 들어간다.
- 서버 실행 기록에는 요청 처리 과정의 기술적인 내용(요청 종류, 응답 상태, 오류)이 남는다.
- 학생 시험 운영 기간에는 사용 통계를 남긴다. 적는 칸은 시각(분 단위), 도구 이름, 성공 여부, 실패 종류, 걸린 시간, 판정 결과(가능/불가/확인 필요)와 신뢰도뿐이다. 학생이 입력한 학과·학년·재학 상태, 검색어, 공지 번호, 접속 주소는 적지 않는다. 이 통계는 서비스 개선과 대회 발표에만 쓴다.
- 서버 앞단의 Cloudflare(터널)는 접속 주소(IP) 등 요청 정보를 자체적으로 처리·보관할 수 있다. 이 처리는 Cloudflare의 정책을 따른다.

## 외부 전송

조회 결과는 요청을 보낸 AI 앱에만 전달된다. 외부로 다시 보내거나 재배포하지 않는다.
