# 작업카드 01 — 공지 본문 평탄화 (`get_notice`)

> 담당: mnzsuu(서브 개발) · 리포: `hackathon_mjc_mcp` · 절차는 `개발절차서.md`
> 상태: 초안 · 팀장 확인 전. **[확인]** 리포에서 직접 확인 / **[제안]** 팀장이 정한 기본안(바꿔도 된다)

## 목표

`get_notice`가 돌려주는 `body`에서, 한 문장이 태그마다 줄바꿈으로 쪼개지는 문제를 없앤다. 판정 로직이 이 본문에서 대상·기간을 읽기 때문에 문장이 이어져야 한다.

## 배경

- 지금: `tools/notices.py`의 `parse_notice_detail()`이 `memo.get_text("\n", strip=True)`로 본문을 만든다(123행). 텍스트 조각마다 줄바꿈을 넣어, `<span>2026</span><span>학년도</span>`가 `2026⏎학년도`처럼 나온다. [확인: 코드]
- 실제 증상: `2026 ⏎ 학년도 2 ⏎ 학기`처럼 나오고 표 구조가 사라진다. [확인: 2026-10-10 실제 공지 조회 결과]
- 이 카드에서 건드리는 것은 **본문 텍스트 만들기**뿐이다. 이미지 전용 공지 안내문, `body_images`, `attachments`, 4000자 절단 동작은 그대로 둔다.

## 요구사항

1. **인라인 요소**(`span`, `strong`, `b`, `em`, `u`, `font`, `a`, `sup`, `sub` 등) 안과 사이에는 줄바꿈을 넣지 않고 이어 붙인다.
2. **블록 요소**(`p`, `div`, `li`, `br`, `h1`~`h6`, `tr`)의 경계에서만 줄바꿈한다. `<br>`은 줄바꿈이다.
3. **표(`table`)**: 한 행(`tr`)을 한 줄로 하고 셀은 ` | `로 구분한다. 병합 셀 등 복잡한 표를 완벽히 처리할 필요는 없고, 정보가 사라지거나 순서가 뒤섞이지 않으면 된다. [제안]
4. 여러 줄의 빈 줄은 한 줄로 줄이고 앞뒤 공백은 제거한다.
5. 결과가 같은 입력에 항상 같아야 한다(순서·공백 안정).

## 입력(fixture)

- 현재 `tests/fixtures/notice_detail.html`은 이미지 전용 공지라 이 카드를 검증하지 못한다. [확인: 이미지 본문]
- **실제 텍스트 공지 3건**의 원본 bytes를 새 fixture로 추가한다: (a) 인라인 태그가 많은 학사공지, (b) 표가 있는 공지, (c) 일반 텍스트 공지.
- 받는 방법(한 번만, 1초 간격은 `fetch()`가 보장):

```bash
.venv/Scripts/python -c "from common.http import fetch; open('tests/fixtures/notice_text_a.html','wb').write(fetch('https://www.mjc.ac.kr/bbs/data/view.do', params={'menu_idx':'<번호>','bbs_mst_idx':'<BM…>','data_idx':'<BD…>'}))"
```

- 어떤 공지를 고를지는 학교 공지 목록(`search_notices`)에서 위 조건에 맞는 것을 직접 고른다. 고른 3건의 ID를 PR에 적는다.
- fixture에는 개인정보(학생 이름·연락처 등)가 들어 있지 않은지 저장 전에 확인한다. 있으면 다른 공지를 고른다.
